Hidebar

Hide the menu-bar icons you don't need. One divider, one click.

Install with Homebrew
brew install --cask pod2metra/tap/hidebar

Download DMG View on GitHub

Free and open source. macOS 15 Sequoia or later.

One divider. Two states.

The divider is a pipe and an arrow. Everything left of the pipe can be hidden; click the arrow to collapse or expand it.

Why open source

Hidebar asks for the Accessibility permission, so you should be able to read what it does with it.

  • Auditable

    The whole app is on GitHub under the MIT license. Read it, build it yourself, or send a fix.

  • No telemetry

    No analytics, no accounts, no network access. Nothing leaves your Mac.

  • Degrades gracefully

    If a permission is missing, Hidebar keeps working with fewer features instead of failing.

Install

Homebrew

brew install --cask pod2metra/tap/hidebar

Disk image

Download the DMG from the latest release, open it and drag Hidebar to Applications.

Build from source

git clone https://github.com/pod2metra/hidebar
cd hidebar
bash scripts/dev_cert.sh   # once: a local signing identity
make run

Needs Xcode 27 (Swift 6.4).

How to use

  1. Arrange. Hold ⌘ and drag an icon to the left of the pipe to hide it, or to the right to keep it visible. This is the system's own gesture.
  2. Collapse. Click the arrow to hide everything left of the pipe, and click it again to show it. Hidebar refuses to hide icons when the arrow would go with them.
  3. Menu. Right-click, Control-click or middle-click the pipe or the arrow for the menu: Show Icon Images… (while Screen Recording is off), How to Use Hidebar…, Quit Hidebar.
  4. Overflow strip. Visible icons that don't fit the bar, behind the notch or under long app menus, appear in a strip below the menu bar. Click one to open its own menu.

FAQ

What about the notch?

Icons that end up behind the notch or under a long app menu aren't hidden, they're just unreachable. Hidebar shows them in a strip below the menu bar so you can still click them.

Why does it need Accessibility?

macOS offers no public way to learn which app owns an icon, or to click it for you. Accessibility is how Hidebar reads icon positions and clicks icons in the strip. Hiding with the divider works without it.

Does it phone home?

No. Hidebar has no telemetry and makes no network connections. The code is public, so you can check.

Which macOS versions are supported?

macOS 15 Sequoia or later.

Will I lose icons if it crashes?

No. The divider's length is restored at launch and at quit, so a crash never leaves an icon hidden.

How do I uninstall it?

Quit Hidebar from its menu, then run brew uninstall --zap --cask hidebar. If you installed from the DMG, drag the app to the Trash.
