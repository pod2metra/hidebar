# homebrew-tap

Homebrew tap for [Hidebar](https://github.com/pod2metra/hidebar), a macOS menu bar
utility that hides menu bar icons behind a single separator.

## Install

```bash
brew install --cask pod2metra/tap/hidebar
```

Or tap first, then install:

```bash
brew tap pod2metra/tap
brew install --cask hidebar
```

## Upgrade and uninstall

```bash
brew upgrade --cask hidebar
brew uninstall --cask hidebar
```

`brew uninstall --cask --zap hidebar` also removes the app's preferences.

## About this repository

`Casks/hidebar.rb` is generated by the Hidebar release workflow from
`packaging/hidebar.rb.template` in the main repository. Do not edit it by hand;
the next release overwrites it.
