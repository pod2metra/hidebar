# SF Symbol catalog for group labels

Status: draft — awaiting approval

Each icon group is shown in the menu bar as a single SF Symbol (template image, ~16pt, monochrome).
All symbols are available on macOS 15 (SF Symbols 6) and were picked to be simple and legible at small sizes.
The catalog is verified with `swift Spikes/SymbolCheck/main.swift docs/SYMBOL_CATALOG.md`.
